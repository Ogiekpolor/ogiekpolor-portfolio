# Moses Garnet Portfolio Website

A modern, responsive personal portfolio website for **Moses Imafidon Ogiekpolor (Moses Garnet)**.

## Features
- Clean, professional design optimized for LinkedIn and professional networking
- Fully responsive (mobile, tablet, desktop)
- Sections: Hero, About, Experience, Skills, Projects, Education, Contact
- LinkedIn integration
- Smooth scrolling navigation

## How to Use
1. Open `index.html` in any modern web browser
2. Or host the entire `portfolio` folder on any static hosting service:
   - GitHub Pages
   - Netlify
   - Vercel
   - Cloudflare Pages

## Customization
- Edit `index.html` to update content
- Edit `styles.css` to change colors or layout
- Replace placeholder content with your photo or additional projects as needed
